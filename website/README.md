# FitAI Websites & Outreach

This directory contains the FitAI marketing website, portfolio site, and lightweight outreach materials.

---

## Structure

- **`fitai-website/`** – Main fit.ai marketing site  
  - See `fitai-website/README.md` for page structure and deployment details.
- **`folio/`** – Emmanuel Ochiba's portfolio site  
  - Includes the FitAI case study page (`fitai.html`) and supporting pages.
- **`DM_SCRIPT.md`** – Template messages for reaching out to potential beta testers
- **`FORM_TEMPLATE.md`** – Google Form structure for collecting beta tester information
- **`TRACKING_TEMPLATE.md`** – Spreadsheet template for tracking outreach and responses

---

## Brand & Logo Assets

The canonical logo and brand assets live in the top-level `logo/` directory:

- SVG and PNG logo variants (dark/light)
- App icon
- Brand color system and usage examples

See `../logo/README.md` for the full brand guide.

---

## Deployment

- **Marketing site (`fitai-website/`)**: Deployed as a static site to `fitailive.com` (Render).
- **Portfolio site (`folio/`)**: Deployed separately (e.g., personal portfolio hosting).

All pages are static HTML and use relative paths for navigation. No build step is required.
